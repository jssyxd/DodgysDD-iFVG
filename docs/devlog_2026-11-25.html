1. 这个项目是什么

DodgysDD 的 Inversion Fair Value Gap（iFVG）策略：价格扫过流动性、三根 K 线留下 FVG，未守住则反转为 阻力/支撑（inversion），在失败的回测处入场，止损放在最近摆动之外，目标下一处流动性。四层结构：

  1. 确定性规则层（strategy/state_machine.py）——因果摆动、一次性扫荡位、ATR 缺口下限、反转窗口 [1,15]/[7,15]、保本完好门、五布尔 checklist（只报告，不过滤）、VXN/DVOL 制度（滞后一天）；
  2. 视觉交叉验证（vision_validator/）——白底 640×640 渲染、对第三根 K 线实体的 2-D IoU、可标定阈值； 原文档的 “IoU > 0.75” 按构造不可达（实测中位数 0.0000，87.9% 恰为 0）；
  3. 元标注（ml_pipeline/）——三屏障标签（2R 目标/1R 止损/未决），6 个月训练 / 1 个月验证 / 1 个月测试 的滚动折，purge 与 embargo，LightGBM，门控只决定“做不做”；
  4. 执行/风控——RL 层（只管理仓位、不能开仓）与 NautilusTrader 策略（strategy/dodgys_strategy.py）。

  • 预注册检验两次都被拒绝：30m 组（5 个加密标的）中位 E_net +0.009 R 但这个簇在 N=72 的 DSR 下 p=0.869； MNQ 15m doc（E_net +0.0769 R, n=998, t=2.22）在 N=106 下 DSR p=0.838。规则在跑之前写死，跑完按规则拒绝。
  • 无 FVG 动量对照：在同一批 1m BTC 数据上，朴素 ATR 动量系统毛边际 +0.0455 R，而 iFVG 规则引擎 −0.0183 R。 即“扣成本前”规则层也没有优势。

3. 数据：从“一周”到“五年”

  • 加密：BTC/ETH/SOL/BNB/XRP 的 1m 到 1d 七个周期（2023-01 → 2026-10/11），由 Binance Vision 5m 拉取或 1m 严格重采样， 完整桶才保留（0 个残缺桶），写前过湖的五条不变量审计；资金费率 5 标的 × 4,200 行（8h），OKX 仅 ~96 天。
  • CME：NQ_1m 实为 3,664,241 根（2015-01 → 2025-07），ES_1m 646,948 根（2020-11 → 2024-07）； 由此重采样出 5m/15m/30m/1h/2h/4h；日线必须用交易所日线（CME 每日维护缺口使 24h 桶永不完整）。
  • 湖里旧的 1h/4h/1d 泳道多为一月残桩（744/186/31 根），这也是此前无法做多年高周期测试的原因。

4. 基准矩阵与候选日志

规则层（无模型）在 98 个格子上跑完：5 个加密标的 + MNQ/MES，7 个周期，2 个预设（honest 代码派生、doc 带 ATR 缺口过滤）， DVOL/VXN 制度，各标的自身 tick 的成本，一次只持一仓（D4）。

  • 70 格为净正；除 30m 外每个周期的中位格为负；70 格最好 t=2.66（XRP 30m honest）在 70 次试验下不构成证据。
  • logs/rule_candidates/：284,083 个候选 × 58 列（含未下单），35 个候选字段 + 全部特征 + 单仓选中标志 + 最终 y （93,386 目标 / 181,271 止损 / 9,426 未决）。

5. NautilusTrader 移植

规则引擎是整段历史条形的纯函数（逐事件调用是二次复杂度），因此 Nautilus 策略消费预计算的候选 feed， 自己负责执行与持仓记账：市价入场 + bracket（限价 TP、止损市价 SL）、一次一仓、可选时间退出；1m 改为逐 bar 手动出场 （bracket 两条腿在同一根 1m bar 内都成交会让净额仓位无符号下溢，实测 Quantity::from_raw raw=3.4e38）。

6. 这条路上的十个真实缺陷

  1. 时区助手把秒当纳秒——所有“纽约时间”偏 5 小时；
  2. 熔断开关被 import 却从未调用；
  3. 未决候选永久占用仓位，单仓组合从 32,521 笔塌到 46 笔；
  4. 参考实现的保本出场被套用到所有 preset；
  5. LightGBM 线程数未固定，引用数字每次漂；
  6. CR1 标准误除以观测数，区间小了约 4 倍；
  7. 28.0 档位边界与特征管线不一致；
  8. 三个退化信号从未被喂过；
  9. “净对净”对比被风险定义操纵（改为毛对毛）；
  10. NaN 被当成“通过”（改为“未评估”）；

以及后来的：NFS 并发写把 16 个分区写成 root 也不可读；Binance 成本档案对所有标的用同一 tick（XRP 每笔 −12 R）； 1m 的 bracket 双腿竞态。

8. 现在的位置

用文档自己的设定（NQ/ES、$4.5 往返 + 1–2 tick、多年 1m）跑完，毛边际在每一个变体上都是负的（NQ doc −0.046 R，ES doc −0.133 R，NQ 全历史 −0.009 R），成本只有 0.03–0.08 R —— 所以“成本决定结论”对 NQ 不成立，规则层本身没有优势。元标注 AUC 0.512；两次预注册都被拒绝。 下一步只剩两类诚实的路：换信息（订单流/OFI、真实 ICT 时段结构、tick 级执行效应）或换设定 （把 NQ/ES 的多年 1m 用在 15m/1h 的信号周期上，让成本占比继续下降）。
